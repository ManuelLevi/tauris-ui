## Default Permission

Lets a window use the tab strip (read its tabs, open, close, move and drag them) and the system's file pickers, which return only what the person chose.

#### This default permission set includes the following:

- `allow-window-state`
- `allow-new-tab`
- `allow-close-tab`
- `allow-activate-tab`
- `allow-move-tab`
- `allow-update-tab`
- `allow-report-strip`
- `allow-drag-out`
- `allow-open-tab`
- `allow-set-close-guard`
- `allow-close-window`
- `allow-move-to-new-window`
- `allow-close-asked`
- `allow-pick-files`
- `allow-save-dialog`
